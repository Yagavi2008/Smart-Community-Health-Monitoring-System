# Smart-Community-Health-Monitoring-System
Smart Community Health Monitoring System is a web-based platform that helps monitor and manage community health records efficiently. It enables users to update health data, track medical history, receive health alerts, and connect with healthcare providers. The system improves healthcare accessibility and supports timely medical assistance.
Smart Community Health Monitoring System

AI-powered Smart Community Health Monitoring System built using React, FastAPI, MongoDB, and Machine Learning to monitor community health, track patient records, predict health risks, and provide real-time health insights for healthcare providers and citizens.

- User Authentication

- Real-Time Health Data Tracking
- AI-Based Health Risk Prediction
- Disease Trend Analysis
